# Progress Protocol

`progress.md` is a mandatory living record.

Before substantial work: **read it**.

After meaningful work: **update it**.

Record:
- current status
- completed
- in progress
- not yet done
- files changed
- experiments run
- actual results
- bugs/blockers
- decisions
- research-question evidence
- next action

Use:
- `ACTUAL` — real experiment/output exists
- `PRELIMINARY` — limited/smoke-test evidence
- `HYPOTHESIS` — expected outcome, not observed
- `UNVERIFIED` — not independently checked

Never invent numbers or fill missing results.

For each RQ, track the relevant experiment, metric/figure/table, actual observation, interpretation, and unresolved issue.
